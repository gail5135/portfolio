> 핵심 역량: 웹 폰트 기반 아이콘을 SVG Sprite로 전환하며, 실제 화면의 스타일 제어 문제와 디자인·개발 간 아이콘 관리 규칙까지 개선한 경험입니다.

Fireside에서는 SVG 아이콘을 웹 폰트로 변환해 사용했습니다. 아이콘을 수정할 때마다 외부 변환 도구를 거쳐야 했고, 크기를 너비·높이 대신 `font-size`로 조절했습니다. 당시 제품에서는 차트나 도형처럼 복잡한 아이콘을 확대하면 형태가 깨져 보이는 문제도 있었습니다.

아이콘 관리 방식에 대한 리서치를 바탕으로 SVG Sprite 전환을 진행했습니다. SVG 파일을 추가하면 생성 스크립트와 공통 컴포넌트를 통해 화면에서 사용하는 구조로 옮기고, 웹뷰와 관리자 콘솔의 기존 아이콘을 순차적으로 교체했습니다.

실제 적용에서는 호출하는 쪽에서 지정한 크기와 색상이 의도대로 반영되지 않았습니다. SVG 내부에 고정된 `fill` 값이 색상 변경을 막고 있어, 단색 아이콘은 `currentColor`를 사용하도록 생성 로직을 수정했습니다. 원본 색상을 유지해야 하는 아이콘은 예외로 구분하고, 변환 과정에서 루트 SVG의 `fill`이 누락되어 배경이 검게 표시되던 문제도 보완했습니다. 크기는 인라인 너비·높이 지정에서 CSS 변수 기반으로 바꿔 사용처의 스타일로 조절할 수 있도록 했습니다.

아이콘 이름도 Figma에서 디자이너가 정한 이름을 개발에서 최대한 그대로 사용할 수 있도록 규칙을 정하고 문서화했습니다. 이를 통해 리소스를 가져와 이름을 지정하고 화면에 적용하는 과정의 기준을 마련했습니다.

전환과 후속 보완을 마친 뒤 기존에 겪던 아이콘 표현 및 크기·색상 제어 문제를 해결했습니다. 이 경험을 통해 공통 컴포넌트를 도입할 때는 기본 표시뿐 아니라 사용처의 스타일 재정의와 원본 표현을 유지해야 하는 예외까지 함께 설계해야 한다는 기준을 얻었습니다.
