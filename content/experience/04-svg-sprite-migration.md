> 핵심 역량: 외부 웹 폰트 변환에 의존하던 아이콘 작업을 프로젝트 내부의 생성 과정으로 옮기고, 화면별 스타일 제어를 보완했습니다.

기존에는 SVG 아이콘을 추가하거나 수정할 때마다 외부 도구에서 웹 폰트로 변환해야 했습니다. 크기도 `font-size`로 조절했고, 복잡한 아이콘은 확대 시 형태가 깨져 보이는 문제가 있었습니다.

저는 SVGR과 SVG Sprite의 사용 방식과 제약을 조사한 뒤 Sprite 기반 구조를 구현했습니다. SVG 파일을 추가하면 빌드 전에 Sprite와 아이콘 이름 타입을 생성하고, 공통 컴포넌트로 호출하도록 했습니다. 웹뷰와 관리자 콘솔의 기존 아이콘도 순차적으로 교체했습니다.

적용 중에는 SVG 내부의 고정된 `fill` 때문에 색상이 바뀌지 않는 문제를 발견했습니다. 단색 아이콘에는 `currentColor`를 적용하고 원본 색상을 유지할 아이콘은 예외로 처리했습니다. 크기도 CSS 변수로 제어하도록 바꾸고, Figma에서 정한 이름을 개발 코드에서 최대한 그대로 쓰도록 규칙을 문서화했습니다.

그 결과 외부 변환 과정 없이 아이콘을 추가하고, 사용처에서 크기와 색상을 조절할 수 있게 됐습니다.
