> 핵심 역량: 외부 도구에 의존하던 아이콘 변환을 자동화하고, 사용처의 크기·색상 제어를 개선했습니다.

기존에는 SVG 아이콘을 수정할 때마다 외부 도구에서 웹 폰트로 변환해야 했습니다. 크기를 `font-size`로 조절했고, 복잡한 아이콘은 확대 시 형태가 깨져 보였습니다.

저는 SVGR과 SVG Sprite를 조사한 뒤 Sprite 기반 구조를 구현했습니다. SVG 파일을 추가하면 빌드 전에 Sprite와 아이콘 이름 타입이 생성되고, 공통 컴포넌트로 호출되도록 했습니다. 웹뷰와 관리자 콘솔의 아이콘도 교체했습니다.

적용 중 고정된 `fill` 값이 색상 변경을 막는 문제를 발견해 단색 아이콘에는 `currentColor`를 적용하고, 원본 색상을 유지할 아이콘은 예외로 처리했습니다.

크기는 CSS 변수로 제어하도록 바꾸고, Figma의 아이콘 이름을 코드에서도 활용하도록 규칙을 문서화했습니다. 이제 외부 변환 없이 아이콘을 추가하고 사용처에서 크기와 색상을 조절할 수 있습니다.
