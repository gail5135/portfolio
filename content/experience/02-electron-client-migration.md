> 핵심 역량: Windows 네이티브 개발자 없이도 팀이 데스크톱 기능을 수정할 수 있도록 클라이언트를 Electron으로 전환했습니다.

기존 클라이언트는 Windows 네이티브 앱 안에서 WebView2로 웹 화면을 실행했습니다. 조직 개편으로 네이티브 개발자가 없어지자 앱 기능을 추가하거나 수정하기 어려워졌습니다. 팀이 활용할 수 있는 JavaScript로 데스크톱 기능을 개발하기 위해 Electron을 조사하고 전환했습니다.

저는 기존 웹 화면을 Electron 렌더러에 연동하고, 앱 잠금 모드와 외부 링크로 앱을 여는 딥 링크 기능을 개발했습니다. Windows와 macOS에서 동작하도록 운영체제별 조건도 반영했습니다.

전환 후에는 웹 개발자가 창 위치·크기를 직접 제어할 수 있게 됐습니다. 외부 모니터를 연결하거나 해제한 뒤 채팅방 창의 위치가 어긋나던 문제도 Electron에서 창 위치·크기 제어를 고쳐 실제로 수정했습니다.

이를 통해 팀이 직접 유지보수할 수 있는 범위를 데스크톱 기능까지 넓혔습니다. 다만 기존 화면이 단일 페이지 애플리케이션 구조가 아니라 여러 렌더러를 관리해야 하는 과제는 남았습니다.
