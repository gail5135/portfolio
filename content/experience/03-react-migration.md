> 핵심 역량: 유지보수가 어려워진 AngularJS 화면을 React로 옮기고, 이후 개발 규칙과 의존성 관리의 기준을 보완했습니다.

입사 당시 메신저는 AngularJS 기반이었습니다. 관련 자료와 커뮤니티 지원이 줄고 공식 지원 종료도 예정되어 있어 전환이 필요했습니다. Vue와 Angular도 검토한 뒤, 문제 해결에 활용할 자료와 라이브러리가 풍부한 React로 전환을 추진했습니다.

저는 채팅방 목록, 메시지 목록, 메시지 작성 등 서비스의 핵심 화면을 React로 이전했습니다. 기존 기능을 새 구조에서 이어 쓸 수 있게 하고, 이후 기능 개발에 React 생태계의 자료와 라이브러리를 활용할 기반을 마련했습니다.

당시에는 일정에 맞춰 기능을 옮기는 데 집중해 디렉터리와 파일 이름 규칙을 충분히 정하지 못했고, TypeScript 경험 부족으로 JavaScript를 사용했습니다. 현재는 신규 파일을 TypeScript·TSX로 작성하며 타입 적용 범위를 넓히고 있습니다.

함께 도입했던 Recoil의 개발이 중단된 뒤에는 Jotai로 전환하고 잔여 의존성을 정리했습니다. 이 경험 이후 기술 선택 때 개발 규칙과 의존성의 유지보수 상태도 살피고 있습니다.
