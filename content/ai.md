> 핵심 역량: AI 기능을 사용하는 화면과 운영 화면을 개발하고, AI 도구가 구현한 결과를 직접 검증했습니다.

### Fireside의 AI 대화 기능과 운영 화면 개발

Fireside의 AI 챗봇과 Text-to-SQL Agent 도입 과정에서 메신저와 관리자 콘솔의 프론트엔드를 맡았습니다. 메신저에는 메시지 전송, 스트리밍 응답과 진행·중지·오류 상태, Markdown 표시를 구현했습니다. 챗봇을 슬래시 명령어로 호출할 수 있도록 관리자 콘솔의 명령어 설정 화면도 만들었습니다.

사용자 질문을 SQL로 바꾸는 Agent의 운영 화면에서는 사용할 데이터베이스를 등록하고 테이블·컬럼 설명을 보강하도록 했습니다. 질의응답 로그의 목록·검색·상세 화면과 사용자 피드백 조회도 구현해, 관리자가 답변 기록을 살펴보고 설명을 보완할 수 있게 했습니다.

대화 화면을 개발할 때는 Markdown 문법 바로 뒤에 한국어 조사가 붙으면 서식이 적용되지 않는 문제를 발견해 렌더링을 보완했습니다. 사용자 대화 화면과 관리자 운영 화면을 함께 개발하며, 응답을 보여주는 흐름부터 로그와 피드백을 확인하는 흐름까지 연결했습니다.

### AI 구현·리뷰 도구를 활용한 개발 워크플로우

요구사항을 바탕으로 Claude Code에 기능 사양과 작업 계획 정리를 요청하고, 이를 GitLab 이슈와 MR에 기록한 뒤 구현에도 활용했습니다. 구현 후에는 Codex 리뷰에서 발견한 문제를 심각도별로 검토하고, 반영할 내용을 사양과 계획에 기록해 수정했습니다.

메시지 목록 윈도잉이 한 사례입니다. 입력창과 목록이 Jotai 상태를 공유해 메시지가 쌓일수록 입력 중 목록이 함께 리렌더링됐습니다. 상태 구조를 크게 바꾸는 방식은 기존 기능에 미칠 영향이 커서, 검색과 이전 메시지 로딩까지 고려해 화면에 보이는 범위만 렌더링하도록 했습니다.

AI가 구현한 결과를 테스트하다 높이가 다른 메시지가 함께 로딩되면 처음 열린 화면이 최신 메시지 대신 목록 중간에 머무는 현상을 찾았습니다. 재현 순서·화면·로그를 전달해 수정을 요청했습니다. 수정본을 다시 테스트해 정상 동작을 확인한 뒤 MR을 승인했습니다.
